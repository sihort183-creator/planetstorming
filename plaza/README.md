# 지금이니!!!

친구들과 함께 입장하는 3차원 주식 광장입니다. 이 폴더에서 파이썬 3.10 이상으로 실행합니다.

```sh
python 광장-서버.py
```

브라우저에서 http://127.0.0.1:8765/ 를 엽니다. 같은 네트워크에서 함께 접속하려면 서버를 `--bind 0.0.0.0` 옵션으로 실행합니다.

## 서버 배포

컨테이너 빌드 경로는 이 폴더입니다. 실행 포트는 기본 8765이며 호스팅 서비스의 `PORT` 환경 변수를 따릅니다. 한 서버 인스턴스를 실행하고 쓰기 가능한 영구 저장소를 `/data`에 연결하면 재시작 뒤에도 참가자와 반응을 복원합니다. 실시간 이동 위치는 서버 메모리에 보관합니다.

주식 가격은 동봉한 종목 목록의 기준가입니다. 모델 출처와 이용 조건은 광장 안의 ‘모델 출처’에서 확인할 수 있습니다.
